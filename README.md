# My IPTV (اپ اندروید)

پخش‌کننده IPTV برای موبایل، تبلت و اندروید تی‌وی که لیست کانال‌ها را از پنل PHP خودتان می‌گیرد.

## ساخت APK با گیتهاب
1. در github.com یک Repository جدید بسازید و همه فایل‌های این پوشه را (با پوشه مخفی `.github`) آپلود/Push کنید.
2. (اختیاری) در Settings → Secrets and variables → Actions:
   - تب Variables: `PANEL_URL` = آدرس پنل، مثل `https://site.com/iptv`
   - تب Secrets: `PANEL_KEY` = کلید API از بخش تنظیمات پنل
   (اگر نگذارید، آدرس و کلید را داخل خود اپ وارد می‌کنید.)
3. تب Actions → «Build APK» → Run workflow (یا با هر Push خودکار اجرا می‌شود).
4. بعد از حدود ۵ تا ۸ دقیقه، پایین صفحه‌ی اجرا در بخش Artifacts فایل `MyIPTV-apk` را دانلود و از حالت زیپ خارج کنید.
5. فایل `app-debug.apk` را روی گوشی/تبلت/تلویزیون نصب کنید (نصب از منابع ناشناس را فعال کنید).

## کنترل‌ها
- کلیک روی کانال = پخش | ⏮ ⏭ = کانال قبلی/بعدی | ⏪ ⏩ = ۱۰ ثانیه عقب/جلو (برای فیلم/VOD)
- ⏯ = پخش/توقف | ⛶ = تمام‌صفحه (دکمه Back خروج از تمام‌صفحه)
- ریموت تلویزیون: Channel +/- و کلیدهای مدیا هم کار می‌کنند.
